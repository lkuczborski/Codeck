01 / THE MAC APP

From source to slides.
In one workspace.

A native document app for writing decks, reviewing AI edits, and presenting live.

Write in Markdown

Headings, tables, images, GIFs, and highlighted code. Separate slides with --- and keep your source readable.

Preview as you edit

See the rendered slide beside your source. Add, duplicate, and organize slides from the sidebar.

Run Codex on a slide

Turn fenced codex blocks into runnable prompt cards. Stream responses live, or run every card on a slide.

Review AI edits

Ask the Deck Assistant to find gaps, shorten, polish, or research. Review proposed changes and choose what to apply.

Present from any slide

Go fullscreen from the selected slide. Navigate with the arrow keys and press Escape to return to your deck.

Connect your agents

Create and edit decks through the file-based MCP server, or enable the live bridge to work with open Mac app windows.

Live cards and the Deck Assistant use your existing Codex login through Codex desktop or the Codex CLI.

GET THE EXTENSION

Add Codeck to Codex.

Run these commands in your terminal to install from the Codeck repository marketplace.

Terminal
codex plugin marketplace add lkuczborski/Codeck
codex plugin add codeck@codeck-plugins

Restart Codex desktop, then open Codeck in the sidebar.

Prebuilt plugin: Apple silicon, macOS 14+, and Codex desktop with workspace extensions. Terminal installation requires Codex CLI and Git. The Codeck Mac app and a separate API key aren’t required.

03 / THE DECK FORMAT

Plain text.
Presentation ready.

Every deck is a readable .mdeck file. Set a theme in the front matter, write Markdown, and use --- between slides. Easy to edit, diff, and version.

hello.mdeck
---
format: codeck.mdeck
version: 1
theme: studio
---
